## Math Refreshers

- [Mathematics for Machine Learning](https://mml-book.github.io/) (free book): linear algebra, calculus, and probability, aimed exactly at ML prerequisites
- [3Blue1Brown: Essence of Linear Algebra](https://www.3blue1brown.com/topics/linear-algebra): visual intuition for vectors, matrices, and eigendecomposition

## Programming

- [NumPy quickstart](https://numpy.org/doc/stable/user/quickstart.html): the official tutorial; most homework starter code assumes this level
- [Python tutorial](https://docs.python.org/3/tutorial/): if you are coming from another language
